# Tonalli releases

Downloads for **Tonalli**, a free, offline knowledge app (library, maps, notes, optional on-device AI)
for Android, Windows and iPhone. This repository holds only the release files and the signed update
feed. See the Releases page for downloads and install notes.

## In-app updates (optional, off by default)

In Tonalli open **Settings -> App updates**, then enter:

- Update address: `siskomx/tonalli-releases`
- Trusted publisher key: `5b08efb736aecf8bfe50d86c65db8df91ce8bcfd68839e55771e811dc15b9bbe`

Turn on **Check for updates** and press **Save**. Tonalli contacts only that address, only after you
turn this on, and accepts an update only if it is signed with the key above.

## Descargas y actualizaciones

Descargas de **Tonalli** para Android, Windows y iPhone: consulta la pagina de Releases. Para
actualizar desde la app: **Ajustes -> Actualizaciones de la app**, con la direccion
`siskomx/tonalli-releases` y la clave de arriba.
